# What I Learned

## 1. Vebble Facilities

Today's session introduced the facilities and ecosystem provided by Vebble for AI development.

---

## 2. Public MCP Servers

Today I learned about Public MCP (Model Context Protocol) Servers.

Public MCP Servers allow AI models to connect with external tools and services using a standardized protocol.

Instead of building custom integrations for every application, developers can use existing MCP servers that expose tools such as:

- File systems
- GitHub
- Databases
- Search engines
- APIs
- Cloud services

Benefits include:

- Easy integration
- Standard communication
- Better scalability
- Faster AI development
- Reusable tools

This concept showed me how AI assistants can perform actions beyond simple text generation.

---

## 3. GLM Open-Source Models

The session also introduced GLM (General Language Model), an open-source family of large language models.

I learned that open-source models provide developers with the flexibility to:

- Download and run models locally.
- Fine-tune models for specific tasks.
- Build custom AI applications.
- Improve privacy by avoiding cloud-based processing.

Open-source AI encourages innovation because developers can study, modify, and improve the models according to their requirements.

## 4. Claude 4 Models

Today's discussion included the latest Claude models developed by Anthropic.

I learned about:

- Claude Opus 4
- Claude Sonnet 4

These models are designed for different purposes.

### Claude Opus 4
- Highest reasoning capability.
- Excellent for research and complex problem-solving.
- Handles long-context tasks efficiently.

### Claude Sonnet 4
- Faster response generation.
- Optimized for everyday AI applications.
- Good balance between speed and intelligence.

Understanding these model variants helped me see how AI companies design models for different use cases instead of relying on a single model.

## 5. Corpus 4.5

Today's session introduced Corpus 4.5.

I learned that a corpus is a structured collection of text or documents used for training, testing, or evaluating AI language models.

Large corpora help AI models:

- Learn language patterns.
- Improve vocabulary.
- Understand context.
- Generate better responses.

Corpus quality directly affects the performance of language models.

## 7. Types of Claude Models

I also learned that Anthropic provides different Claude models for different workloads.

### Claude Haiku
- Fastest model.
- Best for lightweight applications.
- Low latency.
- Cost-effective.

### Claude Sonnet
- Balanced performance.
- Suitable for coding, reasoning, and general AI tasks.
- Most commonly used model.

### Claude Opus
- Most powerful model.
- Excellent reasoning capability.
- Suitable for enterprise AI applications.
- Best for research and complex workflows.

This comparison helped me understand how model selection depends on application requirements.
