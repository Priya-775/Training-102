# Day 5 – Exploring AI Platforms, APIs, and Development Tools

**Date:** 26 July 2026

## Today's Goal
Today's session focused on exploring different AI platforms, APIs, and tools that developers use to build intelligent applications. I learned about various AI models, cloud-based services, local AI execution, and search-powered AI assistants. The session helped me understand how different tools fit into the AI development ecosystem.

---

## What I Learned

### 1. Antigravity
I learned about Antigravity, an AI development platform that enables developers to build AI applications with minimal coding effort. It provides an intuitive environment for creating AI workflows, integrating models, and deploying applications efficiently. It is particularly useful for rapid prototyping and experimenting with AI ideas.

**Key Features**
- Low-code AI development
- Fast application deployment
- Workflow automation
- Easy model integration

---

### 2. Gemini API
Today's session introduced the Gemini API provided by Google. It allows developers to integrate Gemini models into their own applications using APIs.

Using the API, developers can build applications that can:
- Answer user questions
- Generate content
- Summarize documents
- Write code
- Analyze images (depending on the model)

I also learned that API keys are required to securely access Gemini models.

---

### 3. Claude API
Claude API, developed by Anthropic, allows developers to integrate Claude models into their applications.

Claude is designed to provide:
- Helpful responses
- Safe AI interactions
- Strong reasoning capabilities
- Long-context conversations

It is commonly used in AI assistants, document analysis, and enterprise applications.

---

### 4. Alibaba AI Models
Today's session also introduced AI models developed by Alibaba Cloud.

These models support multiple AI tasks such as:
- Text generation
- Language understanding
- Chatbots
- Image-related applications

Alibaba provides AI services mainly through its cloud platform and supports developers in building enterprise-scale AI solutions.

---

### 5. Ollama
One of the most interesting tools I learned about today was Ollama.

Unlike cloud-based AI services, Ollama allows users to run Large Language Models directly on their local computer without sending data to external servers.

Benefits include:
- Better privacy
- Offline AI usage
- Faster experimentation
- Support for open-source models like Llama, Mistral, Gemma, and others

---

### 6. Google AI Studio
Google AI Studio is a web-based platform for experimenting with Gemini models.

I learned that developers can:
- Test prompts
- Generate API keys
- Compare model responses
- Experiment before integrating models into applications

It is an excellent platform for beginners who want to learn prompt engineering and API integration.

---

### 7. Enally
Today's session also introduced Enally as an AI-related platform/tool that helps improve productivity by simplifying AI workflows and supporting faster development. It aims to make AI development more accessible and efficient for developers.

---

### 8. Google AI Mode
I learned about Google AI Mode, which enhances the traditional search experience by providing AI-generated responses instead of only displaying website links.

It combines:
- Search results
- AI reasoning
- Contextual understanding

This enables users to receive more direct and meaningful answers to their queries.

---

### 9. Perplexity AI
Perplexity AI is an AI-powered search assistant that combines the capabilities of search engines and Large Language Models.

Unlike traditional search engines, Perplexity provides:
- Direct answers
- Source citations
- Summaries
- Follow-up questions

This makes research faster and more reliable.

---
